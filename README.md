# Frozen Feast Business Website

This is a responsive website for Frozen Feast, a dessert catering and ice cream truck business. The website allows users to view dessert options, see food photos, explore booking packages, and submit a catering or event request form.

This project was built with HTML, CSS, and JavaScript.

## Features

- Built a clean front-end layout with semantic HTML
- Styled the website with custom CSS
- Used Flexbox and CSS Grid for responsive page layouts
- Added JavaScript DOM manipulation for interactive features
- Created clickable image modals for dessert and gallery photos
- Built an automatic slideshow for event and truck images
- Added smooth scrolling navigation
- Created a mobile-friendly responsive design
- Added a custom favicon using the company logo
- Connected users to the business Instagram page
- Created a booking request form for customer inquiries

## Technologies Used

- HTML
- CSS
- JavaScript
- Formspree
- Visual Studio Code

## What I Learned

While building this project, I learned how to structure a real business website, create responsive layouts, use JavaScript to add interactivity, build image popups, create an automatic slideshow, and connect a customer booking form to a form submission service.
